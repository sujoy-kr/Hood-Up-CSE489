Rotation remains supported; portrait is not locked. Android saved instance state preserves form fields and dynamic admin drafts, while chat messages and queued bookings use SQLite. Process death does not preserve a running HTTP/Firebase callback: stable booking IDs, transaction checks, persisted data and explicit retries provide recovery. A force-stop, task removal or clearing app data is different from system process recreation and may discard transient drafts.

Use test data when checking restored password fields: Android keeps form view state within its task. Database, shared-preference and file data are excluded from cloud/device-transfer backup so a restored installation cannot silently import another installation's session or offline queue. This does not delete owner-scoped cached data on normal logout.
