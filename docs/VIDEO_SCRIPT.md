# Hood Up — 55-second marketing storyboard

Target: **55 seconds**, portrait phone captures composed into the chosen video aspect ratio. Use the real app, demo-owned accounts and readable crops. Record actions at normal speed, then make honest cuts between completed actions. Voiceover is about 100 words; rehearse before editing. This is a storyboard, not a produced video or an assertion that these recordings already exist.

## Recording preparation

- Approve the admin account and publish reviewed rules before recording; cache workshops/services and add a car online. Seed only the dedicated demo project. Hide personal notifications and use demo-owned contact details; do not show passwords, `.env`, API keys, private UIDs or a console credential page.
- Use a future, unoccupied slot during workshop hours. Standard customers cannot take the first opening-hour slot; choose a later one. Do not fabricate booking or notification screens in an editor.
- Gemini success requires a usable configured key and quota. If it falls back, keep the **offline suggestion** label visible and describe it as a local suggestion; do not label that frame as a successful Gemini response. Wait for the real response before cutting to it.
- For shot 7, the admin must perform PENDING → CONFIRMED → IN_PROGRESS → READY. Record the actual customer update and use “Later at the workshop” to show that elapsed service time is omitted. The edit must not suggest a workshop completes work in seven seconds.
- Network and background scheduling can take longer than the shot. Record the full real sequence, then cut out waiting time. If sync/notification delivery fails, fix the setup and re-record; a script is not evidence that it worked.
- Plus has no real payment, pickup dispatch or guaranteed priority over occupied slots. Keep its demo notice readable. The video does not claim real workshop partnerships, actual savings collected, user numbers or verified repair outcomes.

## Edit and export checklist

Use simple cuts and legible captions; lower background music beneath narration. Match each caption to the visible state, especially queued versus sent. Keep the exported duration within 45–60 seconds (this plan totals 55). Check for cropped text/status bars, private notification content and accidental key exposure. Play the final file on the presentation computer and phone before submission. The group still needs to record, edit and export the actual video.
